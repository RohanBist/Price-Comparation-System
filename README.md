# Price Comparison System

A smart web-based application that helps users compare prices of products across different platforms, making it easier to find the best deals.

---

## Features

- Search for products
- Compare prices from multiple sources
- Smart recommendations (e.g., accessories based on search)
- "You May Also Like" suggestions
- Clean and user-friendly interface

---

## Tech Stack

- **Frontend:** (HTML / CSS / JS)
- **Backend:** (Python)
- **Other Tools:** Webscrapper
